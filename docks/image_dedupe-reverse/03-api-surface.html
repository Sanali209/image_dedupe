3.1 Deduper Facade

Deduper.find_duplicates(threshold, include_ignored, roots, progress_callback) → List[FileRelation]
Основной метод: engine.find → persist relations → reconcile с БД → filter
Deduper.set_engine(type) — phash/clip/blip/mobilenet
Deduper.process_clusters(criteria) — Build Graph + Reconcile → clusters
Deduper.save_relations(relations) — Persist to DB (overwrite=False)

3.2 Command System

BaseCommand(ABC) — execute(), undo(), redo(), description
CommandHistory — undo_stack + redo_stack, max_history=50
Actions: MarkDuplicateCommand, ChangeRelationCommand, DeleteFilesCommand, ClearClusterCommand, RemoveFromClusterCommand

3.3 EventBus (Qt Signals)

EventBus() — singleton QObject. Сигналы: scan_started, scan_finished, scan_progress(int,int), file_deleted(str), status_message(str)
bus = EventBus() — глобальный accessor (__new__ singleton)

3.4 Engine API

AbstractEngine(ABC) — initialize(), find_duplicates()
PHashEngine: BK-Tree + MIH candidates → Hamming distance filter
MobileNet/CLIP/BLIP: ChromaDB embeddings → cosine similarity search
