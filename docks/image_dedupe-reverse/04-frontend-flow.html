Pass 2: Архитектура UI

MainWindow использует QStackedWidget — 4 экрана (индексы 0-3): ScanSetup → Progress → Results → Clusters.

ScanSession — единый источник истины (Single Source of Truth) с Qt Signals. Изменение любого свойства (roots, engine, threshold) → config_changed Signal → UI обновляется.

ScanWorker (QThread) — background thread. ThrottledSignal для прогресса (100ms = 10 FPS). 3 этапа в run(): os.walk discovery → indexing (phash/AI extract) → matching (MIH + Hamming).

Компоненты UI

MainWindow (QMainWindow)
├── ScanSetupWidget — выбор папок, engine, threshold
├── ResultsView — QListView virtualization (1M+ pairs)
│   ├── Image A vs Image B (pair view)
│   ├── Visual Difference Mode (heatmap)
│   └── Action buttons: Duplicate/Similar/Crop/Not Dup etc.
├── ClusterView — sticky clusters list + drag-drop
├── ProgressView — прогресс сканирования
└── SettingsDialog — настройки

User Flows

Scan Flow:

Select folders → Choose engine (pHash/AI/CLIP/BLIP) → Set threshold → Scan → Progress → Results appear as pairs

Triage Flow:

Swipe through pairs → Mark as Duplicate/Similar/Crop/Not Duplicate → Auto-skips to next → Undo/redo supported

Cluster Flow:

Drag files to cluster → Rename → Set target folder → Auto-expand on next scan → Context menu: Remove/Delete/Open

UX Patterns

QListView virtualization для 1M+ пар без лага
Visual Difference Mode — heatmap pixel-diff
Dark theme с PySide6 stylesheets
Show Annotated toggle — NEW_MATCH vs все отношения
Status color coding для статусов файлов
