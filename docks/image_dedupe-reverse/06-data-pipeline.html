Pass 2: ScanWorker Pipeline (3 этапа)

1. DISCOVERY: ScanWorker.run() → os.walk(root) → filter extensions (.png,.jpg,.jpeg,.bmp,.gif,.webp) → List[paths]
                      ↓ progress.emit(0, total)
2. INDEXING: Deduper.engine.index_files(files) → phash/AI extract → DB upsert_batch(5000)
                      ↓ ThrottledSignal(100ms) → progress.emit(current, total)
3. MATCHING: Deduper.find_duplicates(threshold, roots) → MIH self-join → Hamming filter
                      ↓ scan_results_ready.emit(results)
   RECONCILE: Deduper проверяет каждую пару против file_relations в БД → обновляет статус
                      ↓ ResultsView (QListView virtual)

pHash Pipeline

Filesystem → Scanner → SQLite (files table)
                           │
                    Extract phash (imagehash)
                           │
                    Store 4×16-bit chunks (MIH)
                           │
                    BK-Tree build (in-memory, pickled cache)
                           │
                    SQL self-join: f1.phash_cN = f2.phash_cN
                           │
                    Candidate pairs → Hamming distance filter
                           │
                    FileRelation(NEW_MATCH) → DB
                           │
                    Deduper.reconcile() → update from existing annotations
                           │
                    ResultsView (QListView virtual)

AI Pipeline (MobileNet/CLIP/BLIP)

Filesystem → Scanner → SQLite
                           │
                    ChromaDB embedding (per engine)
                           │
                    vector_index_status tracking
                           │
                    Cosine similarity search
                           │
                    Threshold filter → FileRelation(NEW_MATCH)
                           │
                    Persist + Reconcile → UI

Cluster Pipeline

GraphBuilder.build_graph_and_find_components()

Loads file_relations from DB → Builds adjacency graph → Finds connected components → Each component = potential cluster

ClusterReconciler.reconcile()

Merges fresh graph components with existing sticky clusters (ID-based). Removes duplicates. Returns final clusters.
