2.1 Pydantic Models

File

Pydantic BaseModel

id: int, path: str, phash: Optional[str], file_size, width, height, last_modified. property: name

FileRelation

Pydantic BaseModel

id1: int, id2: int, relation_type: RelationType(enum), distance: Optional[float], created_at. property: is_visible

Cluster

Pydantic BaseModel

id: Optional[int], name: str, target_folder: Optional[str], created_at

ClusterMember

Pydantic BaseModel

cluster_id: int, file_path: str (normalized), added_at. validator normalize_path.

2.2 RelationType Enum

System: NEW_MATCH (unreviewed)

User decisions: DUPLICATE, NEAR_DUPLICATE, CROP_DUPLICATE, SIMILAR, SIMILAR_STYLE, SAME_PERSON, SAME_IMAGE_SET, OTHER

Negative: NOT_DUPLICATE (explicitly rejected)
