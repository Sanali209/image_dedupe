12. Knowledge

MIH (Multi-Index Hashing)

64-bit hash → 4×16-bit chunks → SQL self-join на любой chunk → ~256x ускорение vs brute force

BK-Tree + pickle cache

BK-Tree строится в памяти, кешируется в bktree_cache.pkl. Hamming distance query O(log n)

Reconciliation после скана

Deduper проверяет каждую новую пару против БД. Если уже annotated — обновляет статус, не создаёт дубликат NEW_MATCH
