1.4 Concepts

P1: MIH (Multi-Index Hashing)

64-bit phash → 4×16-bit chunks. Self-join на совпадение любого чанка. BK-Tree для ускорения.

P2: Plugable Engines

AbstractEngine → PHashEngine, MobileNetEngine, CLIPEngine, BLIPEngine. Deduper.set_engine(type) переключает.

P3: File Relations System

ID-based file_relations с 10 типами (NEW_MATCH, DUPLICATE, NEAR_DUPLICATE, CROP_DUPLICATE, SIMILAR, NOT_DUPLICATE...). Visibility Logic.

P4: Sticky Clusters

Cluster + ClusterMember. ID-based tracking. Auto-expansion при новых сканах.

P5: UndoableCommand

Command Pattern с history: MarkDuplicateCommand, ChangeRelationCommand, etc.

P6: ServiceContainer (DI)

Простой DI-контейнер с singleton registry. Регистрация в main.py.

Pass 2 Additions

  • GPUHasher: PyTorch DCT для GPU-accelerated pHash. DirectML для Windows AMD/NVIDIA
  • ScanWorker (QThread): 3 фазы: Discovery (os.walk) → Indexing (hash/extract) → Matching (MIH → Hamming). ThrottledSignal для прогресса (10 FPS)
  • EventBus: Qt Signal-based singleton. scan_started, scan_finished, scan_progress, file_deleted, status_message
  • ScanSession: reactive properties (roots, engine, threshold, include_ignored) с config_changed Signal. auto-sync scanned_paths с БД
  • MainWindow: QStackedWidget с 4 экранами (Setup→Progress→Results→Clusters). Toolbar + Menu
