User Flows

Scan:

Select folders → engine → threshold → Start → Background scanner → EventBus progress → ResultsView populated

Triage:

Click pair → View side-by-side → Click action (Duplicate/Similar/Crop/NotDup) → CommandHistory records → Auto-advance

Cluster:

Create cluster → Drag files from results → Auto-expand next scan → Rename → Set target → Move files
